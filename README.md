
# Visualization of Sea Ice Data in Alaskan Fisheries Management Regions

This repository contains scripts for creating a data visualization webpage 
that displays sea ice time series across Alaskan fisheries management regions.

The project was initially developed as a collaboration between PolarWatch and the Alaska Fisheries Science Center (AFSC) 
and was made available under a Creative Commons license. 

Building on the initial project, AFSC and AKFIN further developed the webpage to address 
additional sea ice information needs and better support fisheries research and resource management.
